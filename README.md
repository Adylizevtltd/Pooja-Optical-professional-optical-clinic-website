# Pooja Optical Website

Mobile-first functional website for Pooja Optical.

Features:
- Responsive mobile/desktop design
- Click-to-call
- WhatsApp appointment booking
- Appointment form that creates a WhatsApp message
- Google Maps directions
- Services section
- Eye doctor section
- Grand opening offer
- Store gallery with image lightbox
- Sticky mobile call/WhatsApp/book bar
- SEO-friendly title and description

To publish:
1. Upload all files/folders to any static hosting service.
2. Keep the `assets` folder beside `index.html`.
3. No database is required.
